# DoD — Filters & Sorting — controls

Presumes `01-membership` holds. Each group presumes every group above it already holds.

## 1. The filter groups offered
- [ ] 1.1 A filter group shows only where the slice has ≥2 distinct values.

## 2. Options cohere across slices
- [ ] 2.1 Universal options mean, name, and behave identically in every slice.
- [ ] 2.2 No slice-specific option duplicates or clashes with a universal one.

## 3. The sort set
- [ ] 3.1 A sort control shows only where the slice has ≥2 products.
- [ ] 3.2 Exactly six sorts: Newest (default), Price ↑, Price ↓, A–Z, Z–A, Oldest.
- [ ] 3.3 Every offered sort is backed by real product data.
- [ ] 3.4 The same six sorts appear on every surface.

## 4. Option values are clean
- [ ] 4.1 One real-world value = one option (no spelling variants splitting results).
- [ ] 4.2 One casing style across all labels.
- [ ] 4.3 One unit expression per unit type.
- [ ] 4.4 Every label accurate, correctly spelled, one language, no jargon.

## 5. Option order is meaningful
- [ ] 5.1 Brands ordered alphabetically.
- [ ] 5.2 Numeric specs ordered numerically.
- [ ] 5.3 Naturally ranked values in their natural order.

## 6. Price range control
- [ ] 6.1 Range ends equal the real lowest/highest prices in the slice.
