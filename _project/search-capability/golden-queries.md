# Golden queries (human live check)

For each: type it in the header field, note the top 3 suggestions, press Enter, note the top 3 results. Pass = the expected product is in the top 3 of both, and the suggestions' top 6 equal the page's first 6 in the same order (relevance sort, no filters).

| Query | Expect near the top |
|---|---|
| `hd` | Sennheiser HD-series headphones; NOT a DAC whose only "hd" is in specs |
| `hd800s` | Sennheiser HD 800 S |
| `hd 800 s` | same as above |
| `HD-800-S` | same as above |
| `sennheiser` | Sennheiser products, headphones before accessories |
| `sennheiser hd 6` | HD 6xx models |
| `800 sennheiser` | HD 800 S (word order must not matter) |
| `dac` | products with DAC in the name, amp/DAC combos |
| `topping dx3` | Topping DX3 models |
| `amp` | products with "Amp" as a word before mid-word hits (e.g. "Campfire") |
| `iem` | IEM products |
| `fiio` | FiiO products |
| `cable` | cables (accessories are not penalised when the query is a cable word) |
| `focal` | Focal products |
| `dekoni` | Dekoni accessories |
| SKU of any product | that product first |
| `zzzzzz` | no results (SearchEmpty), no suggestions |
