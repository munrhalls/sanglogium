# Feature: Basket Controls

Perspective: User browsing products on search/product detail/products page 

## 1. Objective
Enable users to add and remove items from their shopping basket.

## 2. Scope Boundaries
In Scope:
- Add item to basket from product page
- Remove item from basket
- Show basket item count

Out of Scope:
- Quantity adjustment
- Basket persistence across sessions
- Checkout flow

## 3. Requirements & Definition of Done (DoD)

### DoD [1]: When I browse products, I want to add item to basket
- When I go to products page, I see "Add" button on under each product
- I click it
- Button changes decrement/increment controls and shows me how many items of that product I have in my basket

### DoD [2]: When I browse products, I want to delete item from my basket
- There is no delete button but there is decrement button
- I click decrement button until it's 0 
- I see the product no longer shows controls and count, only "Add" button
- I see cart button count decreases or the count disappeared
