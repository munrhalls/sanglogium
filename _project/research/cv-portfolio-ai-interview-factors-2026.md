# CV vs Portfolio vs Projects vs AI - What Gets Interviews (2026)

## Source-Level Findings

### CV Screening Process (Source: time2work.pl, ITCompare.pl)

**Step 1: Initial CV Review**
- HR specialists review CVs to identify basic qualification matches
- Applicant Tracking Systems (ATS) filter by keywords and criteria
- Polish CVs typically include professional photo (becoming less common)
- Cover letter optional but can differentiate candidates

**Step 2: Phone Screening**
- Brief phone interview assesses: communication skills, motivation, salary expectations, availability
- For candidates passing CV screening

**Critical Finding:** CV gets you to phone screen. Portfolio/GitHub gets you to technical interview. Actual code gets you hired.

### What Matters Most (Source: PrecisionAI Academy, Fortune/CodePath Data)

**Engineering Leaders' Ranking of Signals:**
1. **Side projects/portfolios** - 38% of respondents cite as most important
2. **Internship experience** - 35%
3. **Public code contributions** - Increasingly valued
4. **Formal credentials/degrees** - Lowest priority

**Portfolio Requirements (2026):**
- **Deploy everything publicly** - Live URL signals production understanding
- **README excellence** - "The interview before the interview"
- **Specificity wins** - Domain-specific projects > generic tutorials
- **Real users** - Even 5 users is real; "I built it locally" is weak
- **Original work** - Tutorial clones (to-do apps, Netflix clones) don't move the needle

### GitHub Profile Importance (Source: dev.to, GitHub community discussions)

**GitHub as Technical Resume:**
- GitHub profile is often the first technical signal hiring managers see
- Properly maintained GitHub profiles increase interview callbacks by 40%
- Commit history quality matters (squash messy commits for job hunting)
- README structure signals documentation skills and technical thinking

**README Requirements for Portfolio Projects:**
```
# Project Name - brief tagline
## What It Does
2-3 sentences on problem solved. Link to live demo prominently.
## Screenshot/Demo
## Tech Stack
Why these tools: brief explanation of key decisions
## Key Technical Decisions
1-2 paragraphs on interesting problems solved. What was hard?
## Running Locally
Clear setup instructions
## What's Next
Shows architectural thinking - what would v2 look like?
```

### AI in Recruitment (Source: ITCompare.pl 2025)

**Current State:**
- AI-based pre-screening gaining ground but controversial
- 24% of candidates express complete distrust toward AI selection
- AI evaluates video responses, automated pre-selection
- Candidates fear algorithms miss nonverbal cues and unconventional achievements

**AI Usage by Candidates:**
- AI-generated cover letters and CVs becoming common
- "Fake CVs" and identity fraud rising (candidates constructing local personas)
- Video verification now mandatory to prevent fraud

**Critical Insight:** AI tools help candidates but also create arms race. Authenticity increasingly valuable.

### Biggest Mistakes (Source: Reddit job search discussions, recruitment articles)

**CV Mistakes:**
- Generic CVs not tailored to specific roles
- Lack of quantifiable achievements
- Poor formatting/attention to detail (Polish employers value professionalism)
- Exaggerated skills that can't be verified in technical interview

**Portfolio Mistakes:**
- Tutorial clones (hundreds of to-do apps, weather apps seen by hiring managers)
- No live deployment (GitHub link alone insufficient)
- Poor/no README (missed opportunity to show technical thinking)
- Spending weeks on portfolio site instead of building projects worth showing

**Interview Mistakes:**
- Inability to walk through portfolio work under pressure
- Lack of self-awareness ("I built it this way but in hindsight I'd do X instead" > polished sales pitch)
- Can't explain technical decisions or tradeoffs

### For Your Situation

**CV Strategy:**
- Tailor CV to each role (emphasize React/Next.js/TS/Sanity/e-commerce)
- Include professional photo (Polish norm, though becoming less common)
- Quantifiable achievements: "Built X feature that improved Y by Z%"
- Highlight: headless CMS expertise, e-commerce domain, testing approach

**Portfolio Strategy:**
- Deploy current project publicly (Vercel/Netlify)
- Create excellent README with: problem solved, tech stack rationale, technical decisions, live demo
- Add 1-2 smaller domain-specific projects (not tutorial clones)
- Ensure GitHub profile is clean (squash messy commits, good documentation)

**AI Strategy:**
- Use AI to improve CV/portfolio, not generate from scratch
- Be prepared to discuss AI-assisted work authentically
- Video verification likely - be ready for live screening

**Interview Preparation:**
- Practice walking through current codebase under pressure
- Prepare answers for: "What was hard?", "What would you change?", "Why this architecture?"
- Be ready to explain tradeoffs and technical decisions
- Self-awareness and critical reflection are strong positive signals
