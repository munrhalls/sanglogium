# Ideas

## Prompting Context Patterns

- self referencing micro context
- disciplined recursive micro prompting with self-referencing max freedom micro context
- re-resonating resonance contexts

## Pragmatic Viability Test Plan

Test each idea on same task: "fix failing test in basket-reservation-flow". Self-referencing context: prompt references its own previous output. Recursive micro prompting: break task into self-calling sub-prompts. Re-resonating contexts: multiple context layers reinforce each other. Measure progression rate for each pattern. Compare against baseline direct prompting. Output which patterns improve efficiency.
