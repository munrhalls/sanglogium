# Vertical Slice Plan: Basket Controls

## Slice 1: Basket Controls + Persistence
- User value: User can add/remove items, increment/decrement item quantity, state persists across page refresh
- Scope: ProductPage UI, BasketStore, LocalStorage
- Done when: User adds item, refreshes page, item still there

## Slice 2: Basket Page + Display
- User value: User can view basket contents with totals
- Scope: BasketPage, BasketStore, display logic
- Done when: User sees all items with correct totals

## Slice 3: CMS Synchronization
- User value: Basket state syncs with Sanity backend
- Scope: BasketStore, Sanity API, conflict resolution
- Done when: Basket state matches CMS state, user sees comparision of previous vs current displayPrice/availableStock per item
