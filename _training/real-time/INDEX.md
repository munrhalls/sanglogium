# Real-Time Training Index

## Overview

Real-time training captures organic learning moments during development work. These are raw, immediate lessons extracted from actual work sessions, preserved exactly as discovered.

## Directory Structure

```
real-time/
|
|--- YYYY-MM-DD/           # Daily folders (UNTTOUCHABLE)
|    |--- HH--MM to-HH-MM.md  # Individual session files (ORGANIC)
|
|--- themes/               # Thematic organization (AI-curated)
|    |--- mental-state/         # Mental clarity and presence techniques
|    |--- cognitive-load/        # Information processing and chunking
|    |--- work-modes/           # Productive work states and transitions
|    |--- interference-management/  # Handling toxic thoughts and distractions
|    |--- rhythm-building/      # Building sustainable work rhythms
|    |--- problem-analysis/     # Systematic problem breakdown approaches
|
|--- INDEX.md              # This file
|--- README.md             # System overview
```

## Session Structure

Each session follows this pattern:
1. **Time Range**: HH--MM to-HH-MM (calculated from duration)
2. **Content**: Exact preservation of lessons
3. **Themes**: Cross-referenced to thematic folders
4. **Keywords**: For retrieval and pattern matching

## Usage Protocol

### During Work
1. Notice a learning moment
2. Capture immediately with `/organic-learn`
3. Continue work without interruption

### After Work
1. Review captured lessons
2. Extract key themes
3. Move to appropriate thematic folders
4. Update INDEX.md with new keywords

### Retrieval
1. Before similar work, scan relevant themes
2. Look for patterns in previous sessions
3. Apply learned techniques proactively

## Quality Standards

- **Exact Preservation**: No editing of original content
- **Thematic Cross-Reference**: Lessons linked to themes
- **Keyword Rich**: Easy retrieval and pattern matching
- **Time Stamped**: Chronological tracking of progress
