# Real-Time Training System

## Purpose

Captures organic learning moments during development work, preserving them exactly as discovered and organizing them thematically for future retrieval and compound learning.

## Quick Start

1. **Capture Learning**: Use `/organic-learn` during work
2. **Review Sessions**: Check daily folders for captured lessons
3. **Thematic Organization**: Lessons are automatically organized by theme
4. **Apply Learning**: Use thematic folders before similar work

## File Organization

### Daily Structure
- `YYYY-MM-DD/` - Daily folders
- `HH--MM to-HH-MM.md` - Individual sessions (time calculated from duration)

### Thematic Structure
- `mental-state/` - Mental clarity techniques
- `cognitive-load/` - Information processing methods
- `work-modes/` - Productive work states
- `interference-management/` - Handling toxic patterns
- `rhythm-building/` - Sustainable work rhythms
- `problem-analysis/` - Systematic problem approaches

## Key Techniques Documented

### Heart Breathing
- Slow breaths from center
- Mental headspace clearing
- Alternative to "trying hard"

### Lay of the Land
- Gentle info gathering (< 15 min)
- Puzzle piece organization
- Cognitive load management

### Tiny Writing
- Frame rate acceleration
- Precision and calm
- Focus lock technique

### Uniform Motion Rhythm
- Regular min distances
- Max continuous motion
- Subtle pause patterns

### Huge Failure Pattern Recognition
- Hours with tiny progress
- Helplessness prevention
- Iteration drift awareness

## Integration with Main Training

These real-time lessons complement the structured training system:
- Feed into `_project/lessons/` when codified
- Inform workflow improvements
- Support memory system context
- Enhance sprint planning

## Usage Guidelines

1. **Capture Immediately**: Don't wait, use `/organic-learn` when insight hits
2. **Preserve Exactly**: No editing of original content
3. **Organize Later**: Thematic organization happens after capture
4. **Retrieve Proactively**: Check relevant themes before similar work

## Quality Standards

- **Exact Preservation**: Original content unchanged
- **Thematic Cross-Reference**: Easy theme-based retrieval
- **Keyword Rich**: Pattern matching and search
- **Time Stamped**: Chronological progress tracking
