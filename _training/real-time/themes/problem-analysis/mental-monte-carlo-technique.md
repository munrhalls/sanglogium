# Problem Analysis: Mental Monte Carlo 3D Technique

**Date:** 2026-04-09
**Source:** Real-time sessions and status tracking
**Severity:** Critical
**Frequency:** Systemic (applies to all complex problem-solving)

## The Technique
A 3-dimensional mental simulation approach for exploring problem spaces

## Process Steps

### 1. Start from UX Slices (Front View)
- Begin with user experience perspective
- Establish the front-facing view first
- Ground the simulation in observable user interactions

### 2. Gentle Monte Carlo Expansion
- Gradually explore 2-move, 3-move scenarios
- Monte Carlo the "behind the scenes" implications
- Maintain gentle, non-forceful exploration

### 3. Simplification and Grid-ification
- Simplify down to core components
- Grid-ify the problem space
- Facilitates subtle, gentle, nuanced processing

## Key Characteristics

### Felt Process
- This is a felt, embodied technique
- Not purely intellectual or analytical
- Requires intuitive engagement

### 3D Visualization
- Multi-dimensional problem space
- Front view (UX) to back view (implementation)
- Side views for alternative perspectives

### Gentle Exploration
- No forced conclusions
- Organic discovery process
- Respects complexity and nuance

## Application Context
- Checkout flow design (first successful application)
- Complex system architecture
- User journey mapping
- Problem space exploration

## Prevention Rules
- **DO:** Start with UX/front view
- **DON'T:** Jump to implementation details
- **DO:** Keep exploration gentle and gradual
- **AVOID:** Over-simplifying too early
