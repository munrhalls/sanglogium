## Purpose

This handbook is the definitive reference for orchestrating AI agentic workflows on the Sang-Logium project. It covers everything from fundamental principles to specific command protocols, sprint management, and system coherence maintenance.

## Core Philosophy

> **"Cover first. Then move. Never leave the timeline exposed."**

This handbook operationalizes the military principle of "Cover & Move" for AI-assisted software development:
- **Cover**: Establish defensive positions (testing, validation, scope enforcement)
- **Move**: Advance only when coverage is secure
- **Never leave the timeline uncovered**: Every critical path must have defensive checkpoints

## Critical Rules (Read First)

1. **Deterministic Execution**: All work follows pre-defined phases; no improvisation
2. **Zero Regression**: Every change must mathematically prove no regressions
3. **Scope Containment**: No work outside explicitly defined boundaries
4. **Verification First**: Tests define expected behavior before implementation
5. **Commit Taxonomy**: All commits use Fibonacci difficulty + A/B/C/D/E categorization
