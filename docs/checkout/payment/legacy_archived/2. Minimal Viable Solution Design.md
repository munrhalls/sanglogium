# Technical Solution: Payment Slice

## Pre-requirements
- [ ] Address slice completed (shippingAddress field in basket reservation)
- [ ] Shipping slice completed (shippingChoice field in basket reservation)
- [ ] Stripe account configured with `STRIPE_SECRET_KEY` and `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- [ ] `STRIPE_WEBHOOK_SECRET` configured for webhook signature verification
- [ ] Products in Sanity CMS have `price_data` field with `currency` and `unit_amount`
- [ ] `stripe` (v19.x), `@stripe/react-stripe-js` (v5.x), `@stripe/stripe-js` (v8.x) installed

## Data Actors
- Reservation fetcher → BasketReservation (basketReservation[], shippingAddress, shippingChoice)
- Product price fetcher → Products with price_data (currency, unit_amount)
- Amount computer → total (Σ unit_amount × quantity + shippingChoice.amount), currency
- PaymentIntent creator → Stripe PaymentIntent (client_secret)
- Payment confirmer → stripe.confirmPayment({ elements, confirmParams: { return_url } })
- Webhook handler → Order creation, stock finalization, reservation deletion

## View Actors
- render loading (while creating PaymentIntent)
- render payment form (PaymentElement inside Elements provider)
- render error state (PaymentIntent creation failure or card decline)
- render processing state (while confirming payment)

## Components
- PaymentPage
- PaymentForm (wraps Elements + PaymentElement + submit button)
- OrderSummary (displays basket items, shipping, total)
- ErrorDisplay

## Entities
- basket reservation (Sanity CMS)
- session storage (basketReservationId)
- Stripe PaymentIntent (server-side)
- Stripe Payment Element (client-side)
- payment page

## Data Flow
1. Page mount
2. Get basketReservationId from sessionStorage
3. POST /api/checkout/payment-intent with { basketReservationId }
4. API fetches reservation document from Sanity CMS
5. API fetches product price_data for each item in basketReservation[]
6. API computes total = Σ(product.price_data.unit_amount × item.quantity) + shippingChoice.amount
7. API validates currency consistency across items and shippingChoice
8. API calls stripe.paymentIntents.create({ amount: total, currency, automatic_payment_methods: { enabled: true }, metadata: { basketReservationId } })
9. API returns { clientSecret } to page
10. Page calls loadStripe(NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY)
11. Page renders Elements provider with clientSecret option
12. Page renders PaymentElement inside Elements provider
13. Render: loading | payment form | error
14. User enters payment details in PaymentElement
15. User clicks pay button
16. Page calls stripe.confirmPayment({ elements, confirmParams: { return_url } })
17. Stripe handles 3D Secure / SCA if required
18. Stripe redirects to return_url on success
19. Stripe sends payment_intent.succeeded to webhook endpoint
20. Webhook verifies signature via stripe.webhooks.constructEvent()
21. Webhook creates order in Sanity CMS, finalizes stock, deletes reservation

## API Endpoints

### POST /api/checkout/payment-intent
Request:
- { basketReservationId: string }
Response:
- { clientSecret: string }
Server logic:
1. Fetch reservation from Sanity CMS by basketReservationId
2. Validate reservation exists, has basketReservation[], shippingChoice
3. Fetch product price_data for each basket item from Sanity CMS
4. Compute total = Σ(price_data.unit_amount × quantity) + shippingChoice.amount
5. Validate total > 0, currency consistency
6. Call stripe.paymentIntents.create({ amount: total, currency, automatic_payment_methods: { enabled: true }, metadata: { basketReservationId } })
7. Return { clientSecret: paymentIntent.client_secret }

### POST /api/checkout/webhook
Request:
- Raw body (Stripe webhook event)
- `stripe-signature` header
Response:
- 200 OK (acknowledgment)
Server logic:
1. Verify signature via stripe.webhooks.constructEvent(body, signature, STRIPE_WEBHOOK_SECRET)
2. Filter for event.type === 'payment_intent.succeeded'
3. Extract basketReservationId from paymentIntent.metadata
4. Fetch reservation from Sanity CMS
5. Create order document in Sanity CMS
6. Finalize stock (deduct reserved quantities from real stock)
7. Delete reservation document
8. Return 200
