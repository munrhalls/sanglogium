# SHIPPING PAGE - POLAND ONLY TRACER IMPLEMENTATION

### POLAND ADDRESSES - CARRIER RATES
What API returns carrier rates at 0 monetary cost?

Allekurier API

What exact endpoint and where is it located? 
POST https://allekurier.pl/api_v1/service_list
Location: app/api/shipping/rates/route.ts 

What is the returned data format from that endpoint? 
JSON array with Carrier, Service, Order (net/gross), and Time fields

What is the exact typescript type of that data?

```
    interface AlleKurierService {
    Order: { net: number; gross: number }
    Carrier: { code: string; name: string }
    Service: { code: string; name: string }
    Time: { days: string; description: string }
    }
    type AlleKurierResponse = AlleKurierService[]
```
