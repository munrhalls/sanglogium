# Technical Solution: Shipping Slice

## Pre-requirements
- [ ] Address slice completed (shippingAddress field in basket reservation)
- [ ] Packlink PRO API account and API key configured
- [ ] Company parcel data defined (weight, dimensions)
- [ ] PATCH endpoint for basket reservation updates

## Data Actors
- Reservation fetcher → BasketReservation (shippingAddress, basketReservation array)
- Address + parcel combiner → PacklinkRequest (address, parcel dimensions, weight)
- Packlink PRO API → ShippingOptions (provider, serviceLevel, rateId, amount, estimatedDays)
- Selection handler → ShippingChoice (provider, serviceLevel, rateId, amount, estimatedDays)

## View Actors
- render loading
- render shipping options list
- render error state

## Components
- ShippingPage
- ShippingOptionsList
- ShippingOptionCard
- ErrorDisplay

## Entities
- basket reservation (Sanity CMS)
- session storage (basketReservationId)
- Packlink PRO API
- shipping page

## Data Flow
1. Page mount
2. Get basketReservationId from session storage
3. Fetch reservation document from Sanity CMS
4. Extract shippingAddress from reservation
5. Combine address with parcel data (weight, dimensions)
6. Call Packlink PRO API with address and parcel data
7. Parse Packlink PRO response to ShippingOptions array
8. Render: loading | shipping options list | error
9. User selects shipping option
10. Update reservation document with shipping choice
11. Redirect to payment page

## API Endpoints

### GET /api/shipping/rates
Request:
- basketReservationId (from session storage)
Response:
- ShippingOptions[]

### PATCH /api/basket-reservations/[id]
Request:
- shippingChoice (selected shipping option)
Response:
- Success confirmation
