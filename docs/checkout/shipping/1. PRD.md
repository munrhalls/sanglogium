# Feature: Shipping Slice

## Perspective
User selecting shipping option after address validation in checkout flow

## 1. Objective
User views available shipping options, selects preferred shipping method, and proceeds to payment.

## 2. Scope Boundaries

### In Scope
- Display available shipping options with provider, service level, price, and delivery estimate
- User selection of shipping option
- Save selected shipping option to basket reservation document
- Redirect to payment page on successful selection
- Loading and error states for API calls

### Out Scope
- Address validation (handled by address slice)
- Payment processing (handled by payment slice)
- Shipping label generation (handled in order creation)
- International shipping restrictions
- Multiple shipping addresses

## 3. Definition of Done (DoD)

### Display & Selection
- [ ] DoD [1]: I see available shipping options with provider name, service level, price, and estimated delivery time.
- [ ] DoD [2]: I can select a shipping option from the displayed list.
- [ ] DoD [3]: After selection, I am redirected to the payment page.
- [ ] DoD [4]: My selected shipping option is saved to the basket reservation document.
- [ ] DoD [5]: I see a loading state while shipping options are being fetched.
- [ ] DoD [6]: I see an error message if shipping options cannot be fetched.

### Data Integrity
- [ ] DoD [7]: Shipping options are fetched using my verified address from the reservation document.
- [ ] DoD [8]: Shipping options are combined with parcel data before calling Packlink PRO API.
- [ ] DoD [9]: Selected shipping option includes provider, service level, rate ID, and price.
