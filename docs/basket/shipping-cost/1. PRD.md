# Feature: Shipping Cost Display on Basket Page

## Perspective
User viewing basket page before checkout

## 1. Objective
User sees concrete shipping cost in basket summary based on their origin country, eliminating "fear of the unknown" and preventing cart abandonment from hidden fees.

## 2. Scope Boundaries

### In Scope
- Detect user origin country (PL/GB/DE only)
- Use parcel data already fetched from CMS during basket page load
- Fetch shipping rates via country-specific API
- Select cheapest option as default
- Display shipping cost in basket summary (Subtotal + Shipping + Total)
- Use sender address from environment variables for each country

### Out Scope
- Basket reservation creation (happens later on checkout)
- Checkout shipping method selection (upgrade options)
- Payment flow
- International shipping beyond PL/GB/DE

## 3. Definition of Done (DoD)

### User sees shipping cost in basket summary
- [ ] DoD [1]: I see shipping cost displayed in my basket summary (Subtotal + Shipping + Total)
- [ ] DoD [2]: Shipping cost is calculated based on my detected country (PL/GB/DE)
- [ ] DoD [3]: The displayed shipping cost is the cheapest available option for my country
- [ ] DoD [4]: If I add/remove items, shipping cost updates automatically
- [ ] DoD [5]: Shipping cost uses correct sender address for my country
- [ ] DoD [6]: No extra CMS roundtrips for parcel data (already fetched during basket page load)
