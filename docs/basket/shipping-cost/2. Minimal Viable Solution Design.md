# Technical Solution: Shipping Cost Display on Basket Page

## Pre-requirements
- [ ] Basket page CMS fetch includes parcel data (dimensions, weight) - see issue sang-logium-khp
- [ ] Configure sender addresses in .env for PL/GB/DE (SENDER_ADDRESS_{COUNTRY}_*)
- [ ] Verify AlleKurier API credentials for PL
- [ ] Research and select shipping APIs for GB/DE
- [ ] Configure shipping API credentials for GB/DE

## Data Actors
- CountryDetector -> countryCode (PL/GB/DE)
- BasketPage -> parcel data (from CMS)
- ShippingRatesAPI -> cheapestRate
- BasketSummary -> display shipping cost

## View actors
- render basket summary with shipping cost
- update shipping cost on basket change

## Components
- CountryDetector
- BasketPage (update to use parcel data)
- BasketSummary (update)
- ShippingRatesAPI (new endpoint, separate from checkout flow)

## Entities
- client basket
- product parcel data (CMS)
- shipping APIs (external)
- sender addresses (environment variables)

## Data flow
1. Basket page loads
2. Basket page fetches product data from CMS (including parcel data)
3. CountryDetector detects user country (PL/GB/DE)
4. Basket page constructs default shipping address for detected country
5. POST to new `/api/basket/shipping-rates` with parcel data + country + default address
6. API aggregates parcel data (sum weights, max dimensions)
7. API calls country-specific shipping API
8. API selects cheapest option
9. API returns cheapest rate
10. Basket summary displays: Subtotal + Shipping (cheapest) + Total

## Types
```typescript
type CountryCode = 'PL' | 'GB' | 'DE'

interface CountryDetector {
  detect(): CountryCode
}

interface ParcelData {
  length: number
  width: number
  height: number
  weight: number
}

interface CheapestRate {
  provider: string
  servicelevel: { name: string }
  amount: number
  currency: string
}
```

## Country Detection Strategy
- IP-based geolocation (primary)
- Browser locale (fallback)
- Default to PL (fallback)

## API Integration
- **PL**: AlleKurier API (username/password auth, explicit test mode)
- **GB**: TBD (research required)
- **DE**: TBD (research required)

## Sender Address Selection
1. Try `SENDER_ADDRESS_{COUNTRY}_*` (country-specific)
2. Fallback to `SENDER_ADDRESS_DEFAULT_*`
3. Fallback to base `SENDER_ADDRESS_*`

## Basket Reservation Note
Basket reservation is NOT involved in shipping rate calculation on basket page. That happens later when user clicks checkout.
