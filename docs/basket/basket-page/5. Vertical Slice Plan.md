# Vertical Slice Plan: Basket Page

## Slice 1: Data Layer - Zustand Store with Sync
- User value: Foundation for basket page state management and CMS sync
- Scope: basketStore.ts (syncWithCMS action, Zod validation, comparison logic)
- Done when: syncWithCMS validates CMS data, compares with stored snapshots, updates state with metadata, moves unavailable items

## Slice 2: Component Layer - BasketItemsTable
- User value: Renders basket items with comparison results and quantity controls
- Scope: BasketItemsTable.tsx
- Done when: Table renders items, shows price/stock comparison, quantity controls dispatch store actions

## Slice 3: Component Layer - SyncStatusBar
- User value: Shows sync status (loading, success, error with retry)
- Scope: SyncStatusBar.tsx
- Done when: Renders sync status, dispatches retry action on error

## Slice 4: Component Layer - CheckoutButton
- User value: Renders checkout button with disabled state during sync/error
- Scope: CheckoutButton.tsx
- Done when: Button disabled during sync/error, enabled on success

## Slice 5: Component Layer - UnavailableItems
- User value: Renders unavailable items banner and list
- Scope: UnavailableItems.tsx
- Done when: Banner shows unavailable count, list renders unavailable items

## Slice 6: Component Layer - EmptyBasket
- User value: Renders empty state with browse products button
- Scope: EmptyBasket.tsx
- Done when: Shows empty state message, button navigates to products page

## Slice 7: Page Integration - Basket Page
- User value: Complete basket page with all components integrated
- Scope: Basket.tsx, all basket components
- Done when: Page renders all components, syncs on mount, handles empty state

## Slice 8: CMS Integration - Product Data Fetch
- User value: Fetches product data from CMS for sync comparison
- Scope: getBasketProducts.ts, GROQ query
- Done when: Fetches products by IDs, returns required fields (price_data, stock, reservedStock)
