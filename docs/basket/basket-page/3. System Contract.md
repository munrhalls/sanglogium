## 1. State Location
Where does the state live?

## 2. Data Contract
What is the exact TypeScript Interface?

```typescript
interface BasketItem {
  productId: string;
  quantity: number;
  displayPriceAtAdd: number;
  availableStockAtAdd: number;

}

interface BasketState {
  items: BasketItem[];
  unavailable: BasketItem[];
  syncStatus: 'idle' | 'loading' | 'error' | 'success';
}

interface BasketActions {
  syncWithCMS: (cmsProducts: CmsProduct[]) => void;
  adjustQuantity: (productId: string, delta: number) => void;
  removeItem: (productId: string) => void;
}

type BasketStore = BasketState & BasketActions;
```

## 3. Why This Matters
By locking in the data contract, everything else becomes a predictable mathematical reality.
