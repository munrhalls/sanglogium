# Feature: Basket Page

# Perspective: User reviewing basket items on dedicated basket page

## 1. Objective
Users view basket items with real-time inventory sync to identify availability discrepancies before checkout.

## 2. Scope Boundaries
In Scope:
- User perspective - what user sees, can do and experiences
- Display basket items (image, title, price, quantity, per-item total)
- Sync with CMS and show stock/price comparison per item
- Display unavailable items separately
- Show sync status and freeze checkout button until complete
- Adjust quantities (increment, decrement to 1)
- Remove items
- Show empty state
- Show basket item sub-total (price x quantity), basket total cost

Out of Scope:
- Anything outside user perspective - what happens under the hood, how it's implemented, etc.
- Adding products from basket page
- Cross-tab synchronization
- Persistence logic
- Checkout process
- Payment processing
- Shipping address management

## 3. Requirements & Definition of Done (DoD)

### [ ] DoD [1]: When I view basket page, I want to see all my basket items and total price
- When I go to /basket, I see list of items (image, title, price, quantity, per-item total)
- When I go to /basket, I see basket total cost displayed
- Basket total cost updates when I adjust quantities or remove items
- I see empty state when no items

### [ ] DoD [2]: When I view basket page, I want to see sync status
- When I go to /basket, I see "Syncing..." bar at top
- When sync fails, I see error state and retry sync button

### [ ] DoD [3]: When sync is loading, I want checkout button frozen but can still interact with basket
- When sync is loading, checkout button is disabled
- During sync, I can adjust item quantities (not blocked)
- During sync, I can delete items (not blocked)
- After sync completes, checkout button becomes enabled
- After sync completes, my changes are incorporated into sync results and if I deleted some items from my basket, they are simply not part of the results
- When sync fails, checkout button remains disabled

### [ ] DoD [4]: When sync completes, I want to see comparison results and my basket updated
- When sync completes, if basket item quantity differs from CMS item available stock, I see my old basket item quantity strikethrough crossed and current CMS-synced reduced basket item quantity shown next to it
- When sync completes, if basket item price differs from CMS item price, I see my old basket item price strikethrough crossed and current CMS-synced price shown next to it
- I see my basket updated accordingly (quantities adjusted, items removed if out of stock, price updated to latest status)
- If some or all items are unavailable, I see unavailable items banner and list of unavailable items under it
- If some items are available and some unavailable, I see available items at the top and unavailable items banner and list below them

### [ ] DoD [5]: When I adjust quantity, I want to update item
- When I go to /basket, I see quantity controls per item
- I click increment/decrement, quantity updates immediately but decrement only works up to 1, at 1 decrement button is disabled

### [ ] DoD [6]: When I remove item, I want it deleted
- When I go to /basket, I see remove button per item
- I click remove button, item disappears with animation
