# Feature: Basket Page

## Perspective
User reviewing basket items on dedicated basket page

## 1. Objective
User confirms item details, edits quantities, and sees live availability to finalize their basket for checkout.

## 2. Scope Boundaries

### In Scope
- Item display (image, title, price, quantity, item total)
- Basket sub-total and total cost
- Live availability and price updates
- Quantity adjustments (increase, decrease) and item removal
- Empty state
- Checkout progression

### Out Scope
- System implementation, network handling, or sync logic
- Adding products
- Checkout and payment flows

## 3. Definition of Done (DoD)

### Display & Edits
- [x] DoD [1]: I see my basket items, sub-total, and total cost.
- [x] DoD [2]: I can increase, decrease (up to 1), or remove items, which updates my totals instantly.
- [x] DoD [3]: I see a clear empty state if I have no items.

### Live Availability
- [] DoD [4]: I see when my basket is actively checking live stock and prices.
- [] DoD [5]: While checking, I can edit items but cannot proceed to checkout.
- [] DoD [6]: After checking, I clearly see which items are available and which are unavailable.
- [] DoD [7]: I can proceed to checkout only with confirmed available items.
