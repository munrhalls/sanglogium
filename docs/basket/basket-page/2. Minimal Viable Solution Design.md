# Technical Solution: Basket Page

## Pre-requirements
- [x] Update CMS product schema and all products to use price_data.unit_amount (cents) instead of displayPrice (dollars)
- [x] Check CMS product schema and all products to have fields: stock, reservedStock 
- [x] Create getBasketProducts.ts with minimal GROQ query for basket page needs

## Solution
When user adds new item to basket, client basket store stores displayPriceAtAdd and availableStockAtAdd snapshots. Compare snapshots against current fetched CMS data to display discrepancies.

## Data actors
- Pre-sync basket handler -> pre-sync basket result 
- CMS fetcher -> CMSBasketItems result
- Sync status manager -> checked and updated sync status
- Comparator -> Comparision data (available basket items with disprepancies flag, unavailable basket items)

### Data Layer

CMS Data Fetch
- Input: ProductIds (string[])
- Output: CMSBasketProduct[]
- Call getBasketProducts(basketItemIds)
- Handle response (type CMSBasketProduct)

Data Processing
- Input: CMSBasketProduct[]
- Output: { displayPrice, availableStock, unavailableItems }
- Process price_data (cents) → convert to display price
- Calculate availableStock = stock - reservedStock
- Identify unavailable items (availableStock < quantity)

Comparison
- Input: BasketItem[] + CMSBasketProduct[]
- Output: { priceDiscrepancies, stockDiscrepancies }
- Component maps over basket items
- For each item, find matching CMS product
- Compute displayPriceAtAdd vs current display price
- Compute availableStockAtAdd vs current availableStock
- Mark price discrepancies
- Mark stock discrepancies

### View Layer

Basket Rendering
- Page load/refresh → check client basket
- If empty → wait for hydration (hasHydrated flag)
- If still empty after hydration → render empty state
- If not empty after hydration → render client basket items
- Update basket table with comparison results
- Render unavailable items banner
- Render basket total
- Render checkout button

Sync Status Management
- Set sync status to loading
- Set sync status to success/error
- Render sync status bar
