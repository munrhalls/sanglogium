# Folders and Files Tree Overview: Non-Local Basket

```
store/
├── basketStore.ts - Zustand store: manages basket state with persist middleware for localStorage and cross-tab sync

components/
├── features/basket/
│   ├── BasketControls.tsx - component: renders basket controls with isBasketPage prop (add/increment/decrement on product pages, increment/decrement/remove on basket page)
│   └── BasketButton.tsx - component: renders header basket button with badge count

app/components/features/products/
├── ProductCard.tsx - component: integrates BasketControls (isBasketPage={false}) for product grid items
├── ProductInfo.tsx - component: integrates BasketControls (isBasketPage={false}) for product detail page
└── RelatedProducts.tsx - component: integrates BasketControls (isBasketPage={false}) for related products section

app/(store)/search/
├── SearchResults.tsx - page: integrates BasketControls (isBasketPage={false}) for search results items

app/components/features/search/
├── AutocompleteItem.tsx - component: integrates BasketControls (isBasketPage={false}) for search autocomplete items

app/components/layout/header/
└── Header.tsx - component: integrates BasketButton for navigation
```
