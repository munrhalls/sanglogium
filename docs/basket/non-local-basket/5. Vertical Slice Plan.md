# Vertical Slice Plan: Non-Local Basket

## Slice 1: Data Layer - Zustand Store
- User value: Foundation for basket state management
- Scope: basketStore.ts (Zustand with persist, Zod validation, fallback storage)
- Done when: All store actions tested (add, remove, increment, decrement), persistence works, hydration validation works

## Slice 2: Component Layer - BasketControls
- User value: Reusable add/increment/decrement/remove buttons
- Scope: BasketControls.tsx
- Done when: Component renders correctly, dispatches store actions on user interactions

## Slice 3: Component Layer - BasketButton
- User value: Header basket button with badge count
- Scope: BasketButton.tsx, selectTotalItemsCount selector
- Done when: Badge shows correct count, button navigates to basket page

## Slice 4: Page Integration - Product Detail
- User value: User can manage basket on product detail page
- Scope: ProductInfo.tsx, BasketControls.tsx
- Done when: Can add/increment/decrement/remove product on product detail page

## Slice 5: Page Integration - Product Grid
- User value: User can manage basket from product grid
- Scope: ProductCard.tsx, BasketControls.tsx
- Done when: Can add/increment/decrement/remove product from product grid

## Slice 6: Page Integration - Search
- User value: User can manage basket from search results and autocomplete
