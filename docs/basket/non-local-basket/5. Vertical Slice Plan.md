# Vertical Slice Plan: Non-Local Basket

## Slice 1: Data Layer - Zustand Store
- User value: Foundation for basket state management
- Scope: basketStore.ts (Zustand with persist, Zod validation, fallback storage)
- Done when: All store actions tested (add, remove, increment, decrement), persistence works, hydration validation works

## Slice 2: Component Layer - BasketControls
- User value: Basket controls for both product pages and basket page (add/increment/decrement on product pages, increment/decrement/remove on basket page)
- Scope: BasketControls.tsx with isBasketPage prop
- Done when: Component renders correctly for both contexts (isBasketPage={false} and isBasketPage={true}), dispatches store actions on user interactions

## Slice 3: Component Layer - BasketButton
- User value: Header basket button with badge count
- Scope: BasketButton.tsx, selectTotalItemsCount selector
- Done when: Badge shows correct count, button navigates to basket page

## Slice 4: Page Integration - Product Detail
- User value: User can manage basket on product detail page
- Scope: ProductInfo.tsx, BasketControls.tsx (isBasketPage={false})
- Done when: Can add/increment/decrement product on product detail page

## Slice 5: Page Integration - Product Grid
- User value: User can manage basket from product grid
- Scope: ProductCard.tsx, BasketControls.tsx (isBasketPage={false})
- Done when: Can add/increment/decrement product from product grid

## Slice 6: Page Integration - Search
- User value: User can manage basket from search results and autocomplete
- Scope: SearchResults.tsx, AutocompleteItem.tsx, BasketControls.tsx (isBasketPage={false})
- Done when: Can add/increment/decrement product from search results and autocomplete

## Slice 7: Page Integration - Basket Page
- User value: User can manage basket on basket page
- Scope: Basket page, BasketControls.tsx (isBasketPage={true})
- Done when: Can increment/decrement/remove product on basket page

## Slice 8: Cross-Tab Synchronization
- User value: Basket state syncs across tabs
- Scope: persist middleware storage event handling
- Done when: Changes in one tab reflect in other tabs automatically
