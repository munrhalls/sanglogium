# Velocity Checklist: The 75-Minute Sprint

## 1. Pre-Flight (T-Minus 5m)
* [ ] **Atomic Assets:** Assets (e.g., SVG/WebP) are exported with tight bounds and transparency.
* [ ] **Environment:** VS Code and Browser Lab/DevTools are open and synced.
* [ ] **Zero-State:** A clean component or sandbox is ready for isolated testing.

## 2. The Glossary Dump (10m)
* [ ] **Scan:** Review the flat list of keywords and technical "levers."
* [ ] **Discard:** Identify and skip concepts already intuitively understood.
* [ ] **Anchor:** Select the 2-3 "Lead Domino" terms for the session.

## 3. The Breaking Lab (30m)
* [ ] **Test 1: Visibility:** Intentionally make the element disappear/reappear.
* [ ] **Test 2: Interaction:** Run 3 rapid-fire blend-mode or filter variations.
* [ ] **Test 3: Stress:** Resize the window/CPU to find the "breaking point" of the layout.

## 4. The Blueprint (20m)
* [ ] **Synthesis:** Translate Lab observations into a single, robust CSS/Tailwind object.
* [ ] **1-to-1 Awareness:** Verify every line of code has a clear purpose.

## 5. The System Audit (10m)
* [ ] **Coherence:** Check for 2nd/3rd order consequences on the whole system.
* [ ] **Velocity Calculation:** Compare actual time spent vs. 75-minute target.
